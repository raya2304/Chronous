# Chronos – World of Watches

Chronos is a modern and elegant one-page website dedicated to the world of watches. The project showcases luxury timepieces, watch styles, movements, craftsmanship, and the evolution of watchmaking through a visually rich and responsive interface.

## Overview

The website is designed with a premium aesthetic using a combination of dark backgrounds, champagne-gold accents, elegant typography, and high-quality watch imagery.

It provides an engaging way to explore different types of watches while presenting information about their designs, movements, history, and craftsmanship.

## Features

* Premium luxury-inspired design
* Responsive layout for desktop, tablet, and mobile
* Hero section with featured watch imagery
* Watch collection with multiple timepieces
* Classic, luxury, sport, vintage, and minimalist styles
* Watchmaking and craftsmanship section
* Information about mechanical, automatic, and quartz movements
* Watchmaking history timeline
* Hover effects and smooth visual transitions
* Elegant typography and spacing
* Structured footer and navigation

## Technologies Used

* HTML5
* Tailwind CSS
* Google Fonts

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/chronos-world-of-watches.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd chronos-world-of-watches
```

### 3. Run the website

Open `index.html` directly in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## Sections

### Hero

Introduces Chronos with a large featured watch image and an overview of the website.

### Timeless Icons

Explains the important components and craftsmanship behind mechanical watches.

## Responsive Design

The website is designed to adapt to different screen sizes using Tailwind CSS responsive utility classes.

It provides a consistent experience across:

* Desktop
* Laptop
* Tablet
* Mobile

This project was created as a front-end design project to practice building a visually appealing and responsive website using HTML and Tailwind CSS without JavaScript.
